# Backend Engineering Glossary

This glossary contains engineering terms encountered during the development of this project.

---

## Bootstrap

**Persian**

راه‌اندازی اولیه پروژه

**Definition**

The process of initializing and preparing an application before it starts serving requests.

---

## Boilerplate

**Persian**

کد یا ساختار اولیه تکرارشونده

**Definition**

A reusable project template or starter code that reduces repetitive setup work.

---

## Scaffold

**Persian**

اسکلت اولیه پروژه

**Definition**

The initial folder and file structure generated before implementing business logic.

---

## Endpoint

**Persian**

نقطه دسترسی API

**Definition**

A specific URL exposed by the server to handle client requests.

---

## Middleware

**Persian**

میان‌افزار

**Definition**

A function executed during the request-response lifecycle before reaching the final route handler.
